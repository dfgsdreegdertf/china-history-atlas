# 千年纪事 · 中国历史时间轴

从唐朝到今天，沿时间轴查看历史事件、发生地点、历代版图和史料图片。横轴表示时间，纵轴按主题分组。

## 运行和发布

直接用浏览器打开 `index.html`。本项目使用静态 HTML、CSS 和 JavaScript，无需安装依赖或构建。

将这些文件放在 GitHub 仓库根目录，包括 `.nojekyll`。打开仓库的 **Settings → Pages**，选择 **Deploy from a branch**，选定 **main** 和 **/(root)** 后保存。

地图和事件出处可在网页内查看。部分史料图片从原站加载，图片按其标注的来源和许可使用。
